## 3. CHECKLIST BAB 3 — METODE PENELITIAN [L170–210] (Model B §3.1–3.5 [L1176–1186])

### 3.1 Jenis dan Sumber Data [L174–178]
- [ ] Jenis data + dari mana diperoleh dijelaskan.
- [ ] Menurut bentuk: **kualitatif / kuantitatif** (SoT: kuantitatif).
- [ ] Menurut sumber: **primer / sekunder** (SoT: primer — kuesioner Google Forms, TERKONFIRMASI).
- [ ] **Tahun data ditulis eksplisit**, mis. `data penelitian meliputi data tahun 20xx` [L178] (SoT: OPEN — isi setelah pengumpulan, dilarang mengarang tahun).

### 3.2 Populasi dan Sampel [L180–182]
Hanya jika mengambil sampel (SoT: ya). Wajib tiga butir berurutan:
- [ ] **(a) Identifikasi populasi** — karakteristik akurat agar sampel dapat ditentukan (SoT: Gen Z Indonesia; rentang lahir/inklusi = OPEN P06).
- [ ] **(b) Prosedur dan teknik pengambilan sampel** (SoT: OPEN — menunggu kunci + persetujuan pembimbing).
- [ ] **(c) Besarnya sampel final** yang dipakai (SoT: OPEN — N + dasar power belum ditetapkan, DILARANG mengarang N).
- [ ] Kriteria: sampel harus representatif; makin beda dari populasi → makin besar kekeliruan generalisasi [L182].

### 3.3 Model Penelitian — kuantitatif [L186–188]
- [ ] Gambaran teoritis hubungan independen → dependen.
- [ ] **Model persamaan ditulis + bernomor** (rata justify; nomor di kanan/bawah jika panjang [L484–488]).
- [ ] SoT PROPOSED (pilih satu setelah P04 kunci):
  - Opsi A (SPSS regresi): `Y = b0 + b1*X1 + b2*X2 + b3*X3 + e`
  - Opsi B (SmartPLS-SEM): `Y = p1*X1 + p2*X2 + p3*X3 + e` (laten reflektif, indikator OPEN).

### 3.4 Operasionalisasi Variabel — kuantitatif [L190–200]
Tabel wajib 4 kolom per variabel:
- [ ] Variabel penelitian | **Dimensi** tiap variabel | **Indikator** tiap dimensi | **Sumber referensi** variabel+indikator.
- [ ] Definisi operasional jelas/tegas agar pengumpulan + pengujian tidak salah.
- [ ] SoT binding: dimensi/indikator/sumber = OPEN (E02–E03) — selzam tabel tetap OPEN sampai skala T2 terkunci; dilarang mengarang sumber skala.

### 3.5 Metode Analisis Data [L202–210]
- [ ] Jenis analisis dinyatakan: **regresi (parametrik) atau nonparametrik** + langkah sampai uji hipotesis.
- [ ] Jika **regresi parametrik + kuesioner (Model B)**, wajib:
  - [ ] (i) **Uji validitas dan reliabilitas** [L206].
  - [ ] (ii) **Uji asumsi klasik lengkap: normalitas + multikolinearitas + heteroskedastisitas + autokorelasi** [L206].
- [ ] Jika nonparametrik → tidak dituntut persyaratan tersebut [L206] (tidak berlaku untuk Model B regresi).
- [ ] **Software ditulis eksplisit** (contoh pedoman: SPSS for Windows / Lisrel / Eviews [L206]; SoT P04: SPSS vs SmartPLS — PROPOSED).
- [ ] Hilir Bab 4 Model B (untuk konsistensi, bukan dikerjakan di proposal): Demografi Responden → Validitas → Reliabilitas → Asumsi Klasik → Pengujian Hipotesis → Pembahasan [L1190–1200]. Format simpulan H: `H1: X1 berpengaruh positif terhadap Y (lihat p-value + tanda koefisien)` / `H1: X1 tidak berpengaruh terhadap Y (lihat p-value)` [L358–360].

## 7. Falsifier per bagian (yang menggugurkan klaim)

- Bab 1 fenomena: gugur jika sumber bukan ALIVE / angka tak terreplikasi dari sumber asli (pakai `VERIFIED_EMPIRICAL_DATA.md` V/PROPOSED).
- Bab 2 teori/skala: gugur jika acuan < 20, ada skripsi, textbook bukan edisi terbaru, atau skala tanpa jejak validitas di sumber asli.
- Bab 2 hipotesis: gugur jika format bukan `HX: VX berpengaruh positif terhadap Y` atau tanpa uraian studi relevan sebelumnya.
- Bab 3: gugur jika tahun data/N/teknik sampling/software tidak bernama dan tidak terlacak; asumsi klasik kurang satu dari empat (untuk regresi parametrik kuesioner).
- K/T: gugur jika halaman < 50, Turnitin > 30%, jurnal Sinta/Intl < 5, tanpa sitasi dosen FEB, SKS/IPK/Metode Riset tak memenuhi, nama bukan "Tugas Akhir", atau struktur bukan Model B.
